Materi 01

Pengertian & Sistem Bilangan Real

IDE UTAMA Himpunan Bilangan Real (R) menggabungkan seluruh bilangan rasional dan irasional yang dapat direpresentasikan dalam garis bilangan kontinu.

Bilangan Rasional (Q)

Bilangan yang dapat dinyatakan dalam bentuk a/b dengan a, b ∈ Z dan b ≠ 0. Desimalnya berakhir atau berulang.

Contoh: 1/2, -3/4, 0.333..., 5

Bilangan Irasional (I)

Bilangan yang tidak dapat dinyatakan dalam bentuk a/b. Desimalnya tidak berakhir dan tidak berulang.

Contoh: √2, π, e, √5
Materi 02

Sifat-Sifat Operasi Bilangan Real

Untuk setiap bilangan real a, b, c ∈ R, berlaku sifat-sifat aljabar berikut:

Komutatif

a + b = b + a
a × b = b × a

Asosiatif

(a + b) + c = a + (b + c)
(a × b) × c = a × (b × c)

Distributif

a × (b + c) = a·b + a·c
a × (b - c) = a·b - a·c
Elemen Identitas & Invers: Identitas penjumlahan adalah 0, identitas perkalian adalah 1. Invers penjumlahan dari a adalah -a, dan invers perkalian dari a ≠ 0 adalah 1/a.

Materi 04

Nilai Mutlak & Pertidaksamaan

DEFINISI NILAI MUTLAK |x| = x jika x ≥ 0, dan |x| = -x jika x < 0. Nilai mutlak menyatakan jarak suatu bilangan dari titik 0 pada garis bilangan.

Pertidaksamaan Nilai Mutlak

Untuk k > 0:

|f(x)| < k ⇒ -k < f(x) < k
|f(x)| > k ⇒ f(x) < -k atau f(x) > k

Sifat Kuadrat

Metode penyelesaian bentuk |f(x)| < |g(x)|:

f(x)2 < g(x)2 ⇒ (f(x) - g(x))(f(x) + g(x)) < 0

a / 0 = ∞

SALAH 3

log(a+b) = log a + log b

Penjumlahan di dalam logaritma tidak bisa dipecah.

log(a·b) = log a + log b

SALAH 4

-22 = 4

Tanpa tanda kurung, pangkat dikerjakan lebih dulu.

-(22) = -4

SALAH 5

a > b ⇒ ac > bc

Tanda membalik jika c < 0.

c < 0 ⇒ ac < bc

Latihan Soal TKA Matematika Wajib

Uji pemahaman Anda mengenai materi Bilangan Real dengan menjawab soal-soal berikut:

Soal 1 — Pertidaksamaan Nilai Mutlak
Himpunan penyelesaian dari pertidaksamaan |2x - 3| ≤ 5 adalah...
Pembahasan:
|2x - 3| ≤ 5 ⇒ -5 ≤ 2x - 3 ≤ 5
Tambahkan 3 pada ketiga ruas: -2 ≤ 2x ≤ 8
Bagi dengan 2: -1 ≤ x ≤ 4 (Jawaban A).
Soal 2 — Sifat Logaritma
Jika 2log 3 = a dan 3log 5 = b, maka nilai dari 6log 15 adalah...
Pembahasan:
Ubah basis ke 2:
6log 15 = 2log 15 / 2log 6 = (2log 3 + 2log 5) / (2log 2 + 2log 3)
Karena 2log 5 = 2log 3 · 3log 5 = a · b:
6log 15 = (a + ab) / (1 + a) = a(1 + b) / (1 + a) (Jawaban B).
Soal 3 — Bentuk Akar
Bentuk sederhana dari √(7 + 2√10) adalah...
Pembahasan:
Gunakan rumus √[(a+b) + 2√(ab)] = √a + √b.
Cari dua bilangan yang jumlahnya 7 dan hasil kalinya 10 ⇒ yaitu 5 dan 2.
Maka √(7 + 2√10) = √5 + √2 (Jawaban A).
