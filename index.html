Konsep Dasar

1. Sistem Bilangan Real (R)

KONSEP UTAMA Bilangan Real adalah gabungan dari semua bilangan rasional dan irasional yang dapat digambarkan pada garis bilangan.

Bilangan Rasional (Q)

Bilangan yang dapat dinyatakan dalam bentuk a/b dengan a, b ∈ Z dan b ≠ 0. Boleh berupa pecahan atau desimal berulang/berakhir.

Contoh: 3/4, -5, 0.333..., 2.5

Bilangan Irasional

Bilangan real yang tidak dapat dinyatakan sebagai pecahan biasa. Bentuk desimalnya tidak terbatas dan tidak berulang.

Contoh: √2, √3, π, e
Aljabar

2. Sifat Operasi Hitung

Sifat-sifat dasar yang berlaku pada himpunan bilangan real untuk operasi penjumlahan dan perkalian:

Komutatif

a + b = b + a
a · b = b · a

Asosiatif

(a + b) + c = a + (b + c)
(a · b) · c = a · (b · c)

Distributif

a(b + c) = ab + ac
a(b - c) = ab - ac

3. Nilai Mutlak & Pertidaksamaan

NILAI MUTLAK |x| mendefinisikan jarak titik x dari angka 0 pada garis bilangan (selalu bernilai non-negatif).

Sifat |x| < a

Jika |x| < a (dengan a > 0), maka penyelesaiannya:

-a < x < a

Sifat |x| > a

Jika |x| > a (dengan a > 0), maka penyelesaiannya:

x < -a atau x > a
Eksponen & Akar

4. Eksponen & Bentuk Akar

Sifat Eksponen Utama

aᵐ · aⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ

Sifat Bentuk Akar

√(a · b) = √a · √b
√(a / b) = √a / √b
√(a²) = |a|

5. Latihan Pemahaman TKA

Jawab pertanyaan berikut untuk menguji pemahaman Anda:

Soal 1
Manakah dari bilangan berikut yang merupakan bilangan irasional?
Pembahasan: √5 ≈ 2.2360679... memiliki bentuk desimal tak terbatas dan tidak berulang, sehingga termasuk bilangan irasional. √9 = 3 dan 0.75 = 3/4 adalah bilangan rasional.
